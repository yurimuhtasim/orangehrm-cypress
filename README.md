# OrangeHRM Login Automation Testing

Project ini berisi automation testing untuk fitur Login pada website OrangeHRM menggunakan Cypress.

## Tools
- Cypress
- JavaScript
- Visual Studio Code

## Test Cases
Total test case: 12

1. Login valid
2. Password salah
3. Username salah
4. Username dan password salah
5. Username kosong
6. Password kosong
7. Username dan password kosong
8. Username huruf kecil
9. Username dengan spasi
10. Username karakter khusus
11. Password dengan spasi
12. Forgot Password

## Cara Menjalankan
```bash
npm install
npx cypress open
